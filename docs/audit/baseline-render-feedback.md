| RF-01 | P1 | create-game-assets: gameplay read and colour-blind safety; game-ui-ux: "Colour as the only signal ... add an icon, shape or label" | Both armies use the same `bodyPath` silhouettes (`renderer.ts:197`, `soldier-art.ts:117`); the only difference is `BASE` blue `[59,95,138]` vs red `[140,58,52]` (`palette.ts:78-81`).
