## game-ai: fairness ("may only act on what it has seen")

| Check | Result |
|---|---|
| The AI decides from a perception, not the world | ✓ `decide(p, mind, places, rng)` is pure; `perceive` builds plain data from the faction's memory, the hostile armies it can see now, its own armies, holdings and stores, and the static map |
| Memory changes only by sight | ✓ `remember` writes only holdings its sight shows today, plus owner-only news of its own towns (K8.17). The suite audits every order of every persona faction over 360 days on two seeds against that day's perception |
| Unseen changes do not change decisions | ✓ the invariance check changes the world only where a faction cannot see (with a control that it can) and the perception and orders are identical |
| Hidden things stay hidden | ✓ an ambush is invisible but to an army in the same holding; checked at Linnet Cross |
| Same rules as the player | ✓ orders go through `world.check(body, f)` and the one queue; wages, bread, recruiting, hunger, the army cap. The AI's refused orders are dropped, never forced |
| No peeking by pursuit | fixed (KA-03): a chase gave up only when the target was gone, so a pursuer tracked an army it could no longer see |
| Own randomness, replayable | ✓ the `kingdomAi` stream only; orders stamped seq 0, not logged, regenerated by a replay (the soak replays the log to the same hash) |
| Telegraphing | ✓ the rumour card ("Riders seen on the X road, N days out"), warning proportional to towers and scouts; the waves are also told as hearsay in the feed (K8.20). No captain moves on the king before the grace (K8.1) |
| Both outcomes reachable | ✓ each of the three waves is LOST undefended and REPELLED garrisoned in the suite; a thin garrison is fought |
| No degenerate behaviour | ✓ five-year soak on three seeds: no NaN, no negative stock, no stuck army (25 days on the road without arriving, or idle mid-road), the ledger balances daily, the factions keep fielding armies |

## game-ui-ux: the rumour card and the tools

| Check | Result |
|---|---|
| First focus and modal trap | ✓ title focused on open; Tab reaches the first tool and stays in the card (e2e) |
| Clock held while deciding | ✓ `pausesSim`; the e2e checks `now` does not move over six frames |
| Esc | ✓ closes the card ("Let it come"); the rumour stays in the feed |
| Refusals said | ✓ a tool that cannot be used stays in the ring, `aria-disabled`, with "Not possible: …" under it and again in the status line when pressed |
| State in words, not colour | ✓ unavailable tools are dashed AND say why; strength "some N strong" or "strength unknown" |
| Only what the king knows | ✓ the host's strength only if his men can see it; the road named only if he knows the place; how he heard (his own men / the towers and scouts / travellers) |
| Text in tables, 16px floor, reduced motion | ✓ all strings in `invasion-strings.ts`; the card reuses the 16px+ menu classes (title 21px); no new animation (the kingdom UI's reduced-motion rule covers it) |
| One check for button and sim | ✓ every tool is an ordinary order, checked by `world.check` when drawn and at the press |
