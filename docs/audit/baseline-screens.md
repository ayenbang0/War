## Hypotheses (PLAN.md §C.5)

| Hypothesis | Verdict | Evidence |
|---|---|---|
| Zero `aria-*` / `tabindex` / `role` in `index.html`, `src/ui/*`, `main.ts` | **Confirmed** | A grep over those files finds none. `<html>` also has no `lang`. Native buttons limit the damage (BS-11). |
| HUD/overlay type is 11–13px monospace on parchment | **Confirmed, and lower than stated** | `.panel` 11px and `#hud` 13px monospace on `rgba(235,227,209,.78)`; menu section labels go down to 10px (`index.html:169`). Only the chronicle letter uses a serif, at 14px (BS-06). |
| No `prefers-reduced-motion` or `@media` in `index.html` | **Confirmed** | No `@media` of any kind. These DOM screens have no animation to reduce, so here the gap is responsive layout (BS-22), not motion. |
| Ad hoc keyboard handling (`main.ts:264`, `pen.ts:44`, `camera-controls.ts`) | **Confirmed** | `main.ts:264`, `pen.ts:44`/`:98`, `camera-controls.ts:34-35`, each a `window` listener. Home, Menu and Chronicle have no key handling at all, so Esc does nothing there (BS-02). |
| One global `keydown` per module → overlapping key ownership | **Refuted for Home/Menu/Chronicle, confirmed for Tutorial** | The listeners are attached after the screens' awaits (`main.ts:65-89` before `:217-264`), so they don't exist while those screens are up. In the tutorial they all live together: Escape is both stroke-cancel and exit (BS-04), and WASD/arrows (camera) run next to Space, `.` and F2 (main). |
| Colour carries player/enemy identity | **Confirmed (globally); refuted on the chronicle record** | `render/palette.ts:26-27` blue `#3b5f8a` / red `#8c3a34`. Their luminance ratio is **1.15:1**, so they are identical in greyscale. The tutorial's last lesson depends on the player telling the enemy apart (BS-20). Chronicle rows pair colour with the words won/lost. |
